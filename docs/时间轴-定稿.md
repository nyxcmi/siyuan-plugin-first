# 模块定稿：时间轴（timeline）

> 定于 2026-11-18。**这一页是施工依据，改它要经过讨论。**
> 不在这一页上的功能，一律不做。

---

## 一、目标

一个侧栏面板，两个 tab，共用同一份数据：

| tab | 用途 | 读法 |
|---|---|---|
| **时间轴** | 定位："我记得上个月写过什么" | 一天一条，紧凑，点击跳转 |
| **连续阅读** | 沉浸："把这一周重新读一遍" | 全文连排，像一本书 |

---

## 二、数据

**来源**：一个笔记本（默认 `1.daily note`，可在配置里改）。

**每篇取成一个对象**：

```ts
interface DiaryEntry {
  id: string
  date: Date          // 解析优先级：custom-daily-date 属性 → 标题里的 YYYY-MM-DD → 文档创建时间
  title: string       // "2026-11-07 周六"
  text: string        // 原文（markdown）
  plain: string       // 去格式纯文本，取前 300 字，给摘要用
  words: number       // 字数
  mood?: { score: number; emoji: string }   // 当天最后一次心情
  imageCount: number  // 图片数量（不取缩略图）
}
```

**心情怎么取**：查该文档下带 `custom-mood-score` 的块，按 `custom-mood-at` 取最后一条。

**一次取全部**：当前 24 篇、文本量 < 1 MB，不做分页查询。

---

## 三、字段注册表（架构核心）

```ts
const FIELD_REGISTRY = {
  date:     { label: "日期",   render: (e) => 日期标题 },
  title:    { label: "标题",   render: (e) => e.title },
  mood:     { label: "心情",   render: (e) => e.mood ? `${e.mood.emoji} ${e.mood.score}` : "" },
  excerpt:  { label: "摘要",   render: (e, cfg) => 截取(e.plain, cfg.excerptLength) },
  images:   { label: "图片数", render: (e) => e.imageCount ? `${e.imageCount} 张` : "" },
  words:    { label: "字数",   render: (e) => `${e.words} 字` },
  fulltext: { label: "全文",   render: (e) => 渲染 e.text },
}
```

**加新功能 = 注册表加一行，配置界面自动多一个选项。** 渲染逻辑不用改。

---

## 四、默认配置（两套，各自独立）

| | 时间轴 tab | 连续阅读 tab |
|---|---|---|
| 字段 | `date, mood, excerpt` | `date, title, fulltext` |
| 摘要长度 | 50 字 | — |
| 排序 | 新 → 旧 | 旧 → 新 |
| 打开位置 | 顶部（最新） | 滚到最新一天 |
| 分页 | 滚动 | 滚动 / 加载更早 / 按周翻 |

---

## 五、可配置项（只有 4 项）

1. **显示哪些字段**（多选 + 上下移排序）
2. **摘要长度**（数字）
3. **分页方式**（滚动 / 加载更早 / 按周翻）
4. **数据源笔记本**（下拉）

**入口两处，改同一份配置**：

- 面板顶部齿轮 → 改完立刻看到效果
- 插件设置页 → 集中管理

存储：`plugin.saveData("timeline-config", {...})`

---

## 六、交互

| 操作 | 行为 |
|---|---|
| 点日期 / 标题 | 用 `openTab` 打开该篇日记 |
| 切换 tab | 不重新查库，只换渲染 |
| 时间轴条目悬停 | 显示完整日期与字数 |

---

## 七、明确不做（边界）

- ❌ 不修改任何文档（**整个模块只读**）
- ❌ 不渲染图片缩略图（只显示张数）
- ❌ 不做搜索
- ❌ 不做统计图表（属于"回顾视图"）
- ❌ 不做自定义模板 / CSS / 条件规则

---

## 八、风险

| 风险 | 应对 |
|---|---|
| 全文渲染慢 | 分批渲染，每 10 篇一批 |
| 标题解析不出日期 | 三级回退，全失败则按文档创建时间 |
| 心情属性读取失败 | 该项留空，不阻塞整篇渲染 |

---

## 九、验收标准

1. 打开面板 → 两个 tab 都能看到 24 篇日记
2. 时间轴：每条显示日期 + 心情（有的话）+ 50 字摘要
3. 阅读：能连续滚完一整周，全文正常渲染
4. 配置：取消勾选"摘要" → 立刻消失，不用重开面板
5. 点任意条目 → 跳转到对应日记
